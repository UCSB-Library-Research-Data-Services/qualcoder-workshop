Setting Up Your Project

Creating a new project

A QualCoder project is a folder ending in .qda that holds everything: a database, your imported files and your coding. A project called “Test” becomes a folder called Test.qda. For our toy project, we will name it “GitHub”.

  1. Choose Project > Create New Project.
  2. Give it a name and choose where to save it.
  3. To share or hand in the project, zip the whole .qda folder.

The main screen has five tabs: Action log, Manage, Reports, Coding and AI chat. After you change something (for example, add files), use the menu bar to reopen a screen so it refreshes, rather than clicking the tab.

Write a project memo: Adding short memo (about 300–700 characters) describing your research question and data is good practice for future reference and clarity about the project goals and methodology, and the AI tools use it as context. Anything written after a line of ##### is kept private from the AI as we will see in later episodes.

WarningImportant Tips
  • Save projects on your computer’s own drive, not in a cloud-synced folder or on a USB stick. Syncing while QualCoder is open can corrupt the database.
  • Keep backup copies in more than one location. You can use cloud storage, USB drives, external hard drives, or a combination of these options for added protection.

Bringing in your data: Manage Files

All your data comes in through Manage > Manage Files.

Type Formats
Text .txt, .docx, .epub, .md, .odt, .pdf, .rtf, .tex
Images .jpg, .jpeg, .png
Audio and video .mp3, .m4a, .wav, .mp4, .mov, .ogg (and .wmv video)

  • Create a new text file: and type or paste content directly.

Caution

QualCoder should not be used for editing, de-identifying, or pseudonymizing raw data. Best practice dictates importing only final, analysis-ready transcripts and notes into the platform for coding.

Cases & Attributes

Cases group data around a person, place or situation. Attributes are the variables that describe them, such as age group or year of study.

Do you need cases? Not always. If each participant has one interview file, you can put attributes straight on the file. Cases help when one person has several files, or when one file (such as a focus group) holds several people.

Working with cases (Manage > Manage Cases):

  1. Add a case, e.g. Participant 01.
  2. Click the case’s Files cell to link whole files, or highlight part of a text and assign just that passage. Linked text is underlined in red.
  3. Add attribute columns and fill in values.
  4. Import attributes from a CSV or XLSX file: first row = column headings, first column = case names. Names must match exactly, including capitals.
  5. Sort, filter or hide columns with a right-click, and export the table to Excel.

Attribute types: QualCoder offers only two:

  • Character – text values, e.g. “2nd year”.
  • Numeric – numbers, e.g. 21. You can turn numeric into character later, but not the other way round.

Attributes can be attached to files, cases or journals, and managed in Manage > Manage Attributes. QualCoder is not a statistics package; for statistical analysis of attributes, export them to a tool such as R.

NoteWhy this matters for analysis

Attributes will allow you to ask questions like “Do first-year students talk about stress differently from final-year students?”. It allows you to query the data considering demographics and other important characteristics associated with the documents you are analyzing.

References (optional)

If your data includes published articles, you can import a bibliography through Manage > References. This is optional for the workshop but useful for literature reviews.

  • Import RIS or NBIB files (.ris, .nbib or .txt), or pull references straight from Zotero 7 while it is open with its local API turned on.
  • Link each reference to its file. The file then gains four attributes: Ref_Authors, Ref_Title, Ref_Type and Ref_Year.
  • Keep the attributes that start with Ref_; deleting them breaks the link.
  • Export all references as a RIS file.
