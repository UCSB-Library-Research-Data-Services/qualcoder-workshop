# Introduction to Qualitative Data Analysis with Qualcoder

A Quarto website for a 3 hour hands-on workshop introducing researchers to qualitative data analysis with [QualCoder](https://qualcoder.org/)
	
This workshop covers the advantages and best practices of sharing, reusing, and analyzing qualitative data using open tools. Learners will explore secondary datasets from the Qualitative Data Repository (QDR) and master QualCoder—an open-source qualitative data analysis program. Participants can expect to learn how to manage project files, build inductive and deductive coding schemes, conduct axial coding, generate analytical reports, build framework matrices, and export projects using open standards.

## Preview locally

Install [Quarto](https://quarto.org/docs/get-started/), then from this folder run:

```bash
quarto preview
```
